========================================================================
  HOUMI STUDIO — STANDALONE GPU INPAINT SERVER (PyTorch CUDA / Big-LaMa)
========================================================================

How to use:
1. Double click `install_inpaint_server.bat` to install CUDA dependencies (First time only).
2. Double click `run.bat` to start the server (Runs on http://127.0.0.1:2328).
3. In Houmi Studio Settings, go to PERFORMANCE and connect to:
   http://127.0.0.1:2328/inpaint

Supported GPUs:
- NVIDIA GeForce GTX 1650, RTX 2060, RTX 3060, RTX 4060, RTX 4090, etc.
========================================================================

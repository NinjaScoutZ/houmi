### 🔍 การวิเคราะห์ Root Cause

**ปัญหาคือ: ใช้ภาพสังเคราะห์ขนาด 1200x800 แต่ bbox ของบอลลูนจริงอยู่นอกขอบ**

ตัวอย่าง bbox ที่ล้มเหลว:
```
bbox(456, 3750, 255x168)  → y=3750 > 1200 (นอกขอบภาพ)
bbox(65, 6223, 404x165)   → y=6223 > 1200 (นอกขอบภาพ)
bbox(399, 7786, 350x151)  → y=7786 > 1200 (นอกขอบภาพ)
bbox(60, 8191, 325x162)   → y=8191 > 1200 (นอกขอบภาพ)
```

**สรุป**: โปรเจค 138 มีภาพต้นฉบับที่สูงมาก (>9000px) แต่เราใช้ภาพสังเคราะห์ขนาดแค่ 1200x800px

# Antigravity Design (Spatial & Motion UI)

Specialized skill for creating spatial, weightless, and glassmorphic interactive web interfaces.

## Core Tech & Patterns
- **Styling:** Tailwind CSS + 3D CSS Transforms (\perspective\, otateX\, otateY\)
- **Effects:** Glassmorphism (\ackdrop-filter: blur(12px)\, translucent borders, soft diffused shadows)
- **Animation:** GSAP ScrollTrigger, staggered card entrances (0.1s stagger), buttery smooth state transitions (0.3s ease-out)
- **Depth:** Isometric grids, layered Z-axis floating cards, Parallax backgrounds

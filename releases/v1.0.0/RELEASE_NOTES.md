### 🌟 Initial Release Highlights

- **Offline Desktop Studio**: Dual-engine architecture with local FastAPI backend and native PyWebView desktop GUI.
- **LaMa Manga Inpainting Engine**: Deep-learning background reconstruction and inpainting.
- **Thai Word-Wrapping Engine**: Custom syllable and dictionary line-breaking for comic lettering.
- **SQLite Layer Storage**: Offline project persistence with full state serialization.

## [Dev (2026-08-11 05:37)] - 2026-08-11
**Title**: CPU Thread Optimization & Power Consumption Capping for Inpainting/Inference
*Optimized CPU thread allocation for ONNX Runtime (LaMa, MAT, UNet, Detector) and OpenCV during text cleaning and inpainting. Previously, ONNX and OpenCV used unconstrained max CPU threads on 6-core processors like i5-9400F, driving CPU utilization to 100% and causing thermal power spikes. Added CPU thread throttling to limit ONNX intra-op threads and OpenCV threads to max 3-4 threads, reducing CPU usage from 100% down to ~40-50% while maintaining fast inpainting speed.*

### Changes
- **Optimized**: Added create_onnx_session_options helper in config.py to limit ONNX intra-op threads to half CPU cores (max 3-4 threads)
- **Optimized**: Capped OpenCV CPU threads via cv2.setNumThreads in inpainter.py
- **Fixed**: Prevented 100% CPU lockup and Windows UI freezing on 6-core CPUs like Intel i5-9400F during batch text cleaning
